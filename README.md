# Arya Choudhary — Personal Profile Website

A responsive personal profile webpage created with HTML and CSS.

## Project files

- `index.html` — webpage structure and content
- `style.css` — colours, typography, spacing, layout, and responsive design
- `profile.jpg` — profile photograph

## Publish with GitHub Pages

1. Sign in to [GitHub](https://github.com/) and select **New repository**.
2. Name the repository `personal-profile`, set it to **Public**, and create it.
3. Select **Add file → Upload files**.
4. Upload `index.html`, `style.css`, and `profile.jpg` from this folder, then commit the files.
5. Open **Settings → Pages** in the repository.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select the `main` branch and the `/ (root)` folder, then select **Save**.
8. After deployment finishes, the website will normally be available at:

   `https://YOUR-GITHUB-USERNAME.github.io/personal-profile/`

Open the URL and check that the photograph, navigation links, and email link work correctly before submitting it.
